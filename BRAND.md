# TOKENMAXX brand

## Personality

Dry · Competitive · Precise. Short copy. No corporate fluff. No “unleash.”

## Mark

Black square (`#171717`) with mint dither cells (`#28D26E`) — ordered Bayer-like grid. Source: `public/brand/mark.svg` and `BrandMark` component.

## Wordmark

`TOKENMAXX` in Instrument Serif. Always uppercase. Never “Token Maxx” in UI chrome.

## Palette

| Token | Value | Use |
| --- | --- | --- |
| Paper | `#FAFAF9` | Canvas |
| Ink | `#171717` | Text / CTAs |
| Mute | `#737373` | Secondary |
| Line | `#E5E5E5` | Borders |
| Burn | `#28D26E` | Dither accent only |

Avoid purple gradients, neon cyan, cream+terracotta editorial kitsch.

- “Connect the burn.”
